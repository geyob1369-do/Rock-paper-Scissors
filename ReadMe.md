# Rock Paper Scissors

A simple Rock Paper Scissors game built with HTML and JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## Features

- Play against the computer.
- Random computer choices: rock, paper, or scissors.
- Five rounds per game.
- Score tracking for both players.
- Final winner announcement in the browser console.

## Technologies Used

- HTML5
- JavaScript

## How to Run

1. Clone this repository.
2. Open `index.html` in your browser.
3. Follow the prompts to enter your choices.
4. Open the browser developer console (`F12`) to view the scores and results.
